Общие правила для всех материалов:

- Факты о компании берём только из материалов «Очаково» (`docs/case.md`, `archive/case-materials/`) и `shared/content/`. Суммы пишем со словами «от» и «до вычета налога».
- Пиво, сидр и коктейли не показываем и не упоминаем. ДМС не обещаем: в материалах компании его нет.
- Работа, практика и стажировка только с 18 лет.
- Логотип официальный, из брендбука; цвета и пиктограммы тоже по брендбуку.
- Людей на фото, их имена и цитаты публикуем только с письменного согласия.
- Дизайн листовок и концепцию мерча компания утверждает отдельно.

Суммы и телефоны в этих документах берутся из `shared/content/`. При правке там документы сверяют заново.
